# Kairos - מערכת AI נייטיב לניהול פרויקטים שחוזה, לא רק עוקבת

**Kairos** היא מערכת פול-סטאק לניהול פרויקטים: לוח קנבן, רשימה וציר זמן (גאנט) בזמן אמת,
על גבי מסד נתונים רלציוני, ומעליהם מנוע תכנון שעונה על השאלה שכל מנהל באמת שואל: *"נעמוד ביעד?"*

## יכולות AI (Claude Opus 5.5)

- **סוכן Copilot**: צ'אט שמאחוריו סוכן Claude עם 8 כלים. אפשר לשאול "מי בעומס יתר? תאזן את העבודה" או "צור רשימת משימות להשקה וקשר ביניהן לפי הסדר", והוא קורא את הנתונים החיים, מבצע את השינויים ומציג כל פעולה. הכלים עוברים דרך אותה שכבת API כמו הממשק, בהרשאות המשתמש המחובר, כך שהרשאות, ולידציה, יומן שינויים וסנכרון בזמן אמת חלים גם עליו.
- **פירוק משימה עם AI**: הופך משימה גדולה ל-3 עד 8 תתי-משימות עם הערכות ותלויות, שאפשר לערוך לפני היצירה.
- **הזנת משימה בשפה חופשית**: כותבים "דור צריך לתקן את הבדיקה של הצ'קאאוט עד חמישי, דחוף, בערך 2 נקודות" והטופס מתמלא לבד.
- **דוח סטטוס אוטומטי**: דוח לבעלי עניין שנכתב מנתוני הספרינט, התחזית, הסיכונים והעומסים.
- **"תכנן לי את היום"**: עמוד אישי שחוצה את כל הפרויקטים. Claude מסדר את העבודה להיום לפי דדליינים, עדיפויות, חסימות ותיבת ההתראות, עם נימוק לכל בחירה.
- **טריאז' עם AI**: כותבים כותרת ו-Claude מציע עדיפות, הערכה ותוויות, ממליץ על האחראי המתאים לפי ניסיון ועומס, ומזהיר מכפילויות לפני היצירה.
- **שאל מכל מקום**: שורת פקודה (Ctrl/⌘ K) שמחפשת בכל המשימות, מנווטת לכל פרויקט, ומעבירה משפט שלם ישר לקופיילוט.

## יכולות מרכזיות

- **חמש תצוגות מסונכרנות**: קנבן עם גרירה ומגבלות WIP, רשימה ממוינת, ציר זמן עם חיצי תלות, תכנון ספרינטים ודשבורד תובנות.
- **שיתוף פעולה בזמן אמת**: כל שינוי נשלח ב-WebSocket לכל מי שצופה בפרויקט.
- **נתיב קריטי (CPM)**: התלויות בין משימות יוצרות גרף מכוון ללא מעגלים (מעגלים נחסמים). המערכת מחשבת מרווח (slack) לכל משימה, מסמנת את השרשרת הקריטית ומתזמנת אוטומטית משימות בלי תאריכים.
- **תחזית מונטה קרלו**: 5,000 סימולציות על בסיס התפוקה היומית האמיתית של הצוות, שנותנות את ההסתברות לסיים את הספרינט בזמן ותאריכי P50/P85/P95.
- **רדאר סיכונים**: משימות באיחור, משימות בעבודה שעדיין חסומות, חריגה ממגבלת WIP, משימות בלי הערכה ועומס יתר על אנשי צוות, כל ממצא עם פעולה מוצעת (למשל "להעביר את PLS-11 ל-May שיש לה 7 נקודות פנויות").
- **תיבת התראות ו-@אזכורים**: שיוך, אזכור בתגובה, תגובות ושינויי סטטוס במשימות שלך מגיעים לתיבה אישית בזמן אמת.
- **נגישות ומקלדת**: ניווט מלא מהמקלדת, פוקוס נראה, תוויות לכל כפתור, דיאלוג אישור לפעולות הרסניות ותמיכה בהפחתת תנועה.
- **היסטוריית שינויים מלאה**: מי שינה מה, מאיזה ערך לאיזה ערך, ותגובות על משימות.
- **ריבוי ארגונים והרשאות**: סביבות עבודה, תפקידי owner/admin/member/viewer, אימות JWT.

## טכנולוגיות

| שכבה | טכנולוגיה |
|---|---|
| צד לקוח | React 19, TypeScript, Vite, גרפים ב-SVG שנכתבו ידנית, גרירה מקורית של HTML5 |
| צד שרת | FastAPI, Pydantic v2, SQLAlchemy 2, WebSockets, JWT ו-bcrypt |
| מסד נתונים | PostgreSQL 16 (ו-SQLite לפיתוח ולבדיקות) |
| AI | Anthropic SDK, Claude Opus 5.5, לולאת סוכן עם כלים, פלט מובנה |
| איכות | 36 בדיקות pytest (כולל לולאת הסוכן עם לקוח Claude מדומה) על SQLite ועל PostgreSQL, CI ב-GitHub Actions |
| פריסה | Dockerfile רב-שלבי ו-docker-compose עם Postgres |

## הרצה

```bash
export ANTHROPIC_API_KEY=sk-ant-...   # אופציונלי: מפעיל את יכולות ה-AI
docker compose up --build
# לפתוח http://localhost:8000 וללחוץ "Try the demo workspace"
```

משתמש דמו: `demo@kairos.dev` / `demo1234`. אפשר לפתוח שני דפדפנים עם משתמשים שונים (`dor@kairos.dev`) ולראות את הסנכרון בזמן אמת.

הוראות לפיתוח מקומי ולהרצת בדיקות נמצאות ב-[README.md](README.md).

## החלטות תכנון

* **לכל סטטוס יש קבוצה סמנטית** (backlog, unstarted, started, completed, cancelled), כך שאפשר לשנות שמות עמודות בחופשיות והאנליטיקה נשארת נכונה.
* **מזהי משימה לפי פרויקט** (`KAI-42`) עם אילוץ ייחודיות.
* **דירוג עשרוני לגרירה**: הזזת כרטיס כותבת שורה אחת, ומספור מחדש אוטומטי כשהמרווח נגמר.
* **יומן שינויים ברמת שדה** שמזין את היסטוריית הפעילות, ה-burndown וקצב הביצוע.
* **תלויות עם זיהוי מעגלים**, שמזינות את חישוב הנתיב הקריטי, תחזית מונטה קרלו ומכ"ם הסיכונים, ומעליהן קופיילוט ה-AI.

הפירוט ב-[docs/architecture.md](docs/architecture.md).
